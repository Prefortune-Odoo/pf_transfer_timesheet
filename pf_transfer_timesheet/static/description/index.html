Transfer Timesheet to Other Project Task

1. Enable the Update Timesheet Project Task option to allow users to update timesheet project and task details; by default, this option is disabled.

2. Select multiple timesheets and click on the Update Timesheets option under the Action menu to update them together.

3. Select the project and task for the selected timesheets, then click on the update timesheet button to apply the changes.

4. You can view the updated project and task details in the selected timesheets.

5. In the Project Task form, the Timesheet tab will automatically update according to the selected project and task changes.
